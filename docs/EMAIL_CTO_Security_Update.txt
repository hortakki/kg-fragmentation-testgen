Hi Team,

I reviewed the current onboarding-related security expectations, and I want us to tighten the baseline before beta.

For credential creation, the previously assumed minimum is no longer sufficient. Please enforce a more conservative password length requirement for newly created accounts.

Also, on dormant registrations: we should not retain unverified personal data for the longer window discussed earlier. Pending accounts that never complete activation should be purged on a much shorter timeline — roughly within a week rather than the earlier month-long approach.

Please treat this direction as taking precedence over prior informal alignment.
